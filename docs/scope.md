# Scope

## MVP goals

- import a local `.osz`
- list osu!standard difficulties
- prepare beatmap timing and hit object state
- render playable objects in the browser
- support local practice play with local score persistence

## Non-goals

- official login or server connectivity
- rankings, leaderboards, or remote score submission
- online beatmap search or download
- bundled official art, skins, or copyrighted map/audio fixtures
- non-standard rulesets in MVP
