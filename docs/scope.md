# Product Scope

`oszillator` is a playful browser-based osu!standard-style player experiment. It is not a ranked client, private server, or utility-first suite; the point is to make clicking circles in a web page feel surprisingly good.

## Supported

- Import a local `.osz` archive.
- List and select osu!standard difficulties.
- Prepare beatmap timing, hit objects, slider paths, and local assets.
- Render circles, sliders, spinners, cursor trails, smoke, backgrounds, and supported videos in the browser.
- Play locally with score, combo, accuracy, judgement counts, and hit offset history.
- Use autoplay and osu!-style modifiers for previews, experiments, and casual play.
- Store library metadata and local scores on the user's machine.

## Out Of Scope

- Official login or server connectivity.
- Rankings, leaderboards, or remote score submission.
- Online beatmap search or download.
- Bundled official art, skins, beatmaps, audio, or video fixtures.
- Non-standard rulesets.
